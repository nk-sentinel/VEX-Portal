Why Tier 3 has no toggle

Tier 3 evidence — CVSS vector, EPSS, KEV, exposure — may raise severity or route a finding to a human. It may never clear one. That is enforced in the domain layer, not by reviewer discipline.

A greyed-out toggle would imply the capability exists and is merely switched off, so the control is absent instead.
